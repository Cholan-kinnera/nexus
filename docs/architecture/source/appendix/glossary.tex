\chapter{Glossary}
\label{app:glossary}

This glossary defines the technical terms, frameworks, concepts, and platforms referenced throughout this document to ensure clarity.

\begin{description}
    \item[\textbf{Artificial Intelligence (AI)}] Computational systems that simulate human cognitive processes, used in Nexus PM for task suggestion breakdown and context summaries.
    \item[\textbf{Application Programming Interface (API)}] A structured set of protocols and rules that allows client applications to communicate with backend server resources.
    \item[\textbf{Content Delivery Network (CDN)}] A globally distributed network of proxy servers that cache static assets close to users, utilized by Vercel for the Nexus PM React client.
    \item[\textbf{Continuous Integration / Continuous Deployment (CI/CD)}] Automated software workflows that format, lint, scan, test, and package code modifications into staging or production builds on every repository push.
    \item[\textbf{Cloud-Native}] Architectures designed specifically to execute within distributed cloud compute platforms, leveraging managed APIs and serverless services.
    \item[\textbf{Container}] A lightweight, standalone, and executable package of software that contains code, runtimes, system tools, libraries, and configurations.
    \item[\textbf{Create, Read, Update, Delete (CRUD)}] The four basic operations of persistent storage, representing the core capabilities of project and task tracking systems.
    \item[\textbf{Docker}] The virtualization software used to package the Nexus PM FastAPI backend and React frontend into consistent, portable container environments.
    \item[\textbf{Entity-Relationship Diagram (ERD)}] A database visualization mapping relational tables, column attributes, primary key linkages, and foreign key boundaries.
    \item[\textbf{FastAPI}] A high-performance, async-first Python ASGI framework used to build RESTful API endpoints with automatic OpenAPI schema documentation.
    \item[\textbf{Gemini}] Google's multimodal generative AI model, integrated via the Google GenAI SDK to handle project and task text processing.
    \item[\textbf{Hypertext Transfer Protocol (HTTP)}] The foundational stateless client-server communication protocol of the Web, secured via TLS/SSL (HTTPS) in production.
    \item[\textbf{JSON Web Token (JWT)}] An open standard (RFC 7519) that defines a compact, self-contained way to securely transmit identity information as a JSON object.
    \item[\textbf{JavaScript Object Notation (JSON)}] A lightweight data-interchange format that is easy for humans to read and write and easy for machines to parse.
    \item[\textbf{Kanban}] An agile project management visualization framework displaying active task items as cards across sequential columns (Todo, In Progress, Review, Done).
    \item[\textbf{Large Language Model (LLM)}] Deep learning neural networks trained on massive text datasets, capable of understanding and synthesizing human language.
    \item[\textbf{Open Authorization (OAuth)}] An open standard framework for token-based authorization on the Internet, used via Google OAuth to authenticate users.
    \item[\textbf{Object-Relational Mapping (ORM)}] A programming technique that maps database tables to classes in code, enabling developers to query databases using object-oriented code.
    \item[\textbf{PgBouncer}] A lightweight connection pooler for PostgreSQL, running on Supabase to route transient API queries to a fixed pool of database connections.
    \item[\textbf{PostgreSQL}] A highly stable, ACID-compliant open-source relational database management system, serving as the main data store for Nexus PM.
    \item[\textbf{Role-Based Access Control (RBAC)}] An authorization paradigm where access permissions are mapped to roles, and roles are assigned to users within project scopes.
    \item[\textbf{React}] An open-source, component-based frontend JavaScript UI library managed by Meta, used to build interactive single-page user interfaces.
    \item[\textbf{Redis}] An open-source, in-memory key-value data structure store used for low-latency session caches, dashboard analytics caches, and rate-limiting counters.
    \item[\textbf{Representational State Transfer (REST)}] An architectural style for designing networked applications, using HTTP verbs (GET, POST, PUT, DELETE) to manage resource states.
    \item[\textbf{Software-as-a-Service (SaaS)}] A software licensing and delivery model in which software is centrally hosted and licensed on a subscription basis.
    \item[\textbf{SQLAlchemy}] The SQL toolkit and Object-Relational Mapper for Python, providing database connectivity and query generation for Nexus PM.
    \item[\textbf{Supabase}] A developer-friendly Backend-as-a-Service (BaaS) provider that hosts the managed PostgreSQL instance, connection pools, and automatic backups.
    \item[\textbf{Tailwind CSS}] A utility-first CSS framework used to compose clean, responsive user interfaces directly within React HTML/JS structures.
    \item[\textbf{Vercel}] The cloud hosting platform used to distribute the static React frontend client using its global Edge CDN nodes.
    \item[\textbf{Vite}] A modern, high-speed frontend build tool that manages dev server hot-module replacement and bundles client assets using Rollup.
\end{description}
